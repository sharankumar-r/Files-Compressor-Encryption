Secure File Archiving with Encryption

A streamlined desktop application combining maximum zlib compression with Fernet (AES-128-CBC) symmetric cryptography to package and safeguard your sensitive files.

Author: Sharan Kumar R Python 3.8+ Fernet AES-128-CBC zlib Level 9 Tkinter GUI Cross-Platform

Key Capabilities

Maximum Compression

Files are compressed utilizing Python's native zlib engine at Z_BEST_COMPRESSION to minimize archive size before encryption.

Authenticated Fernet Security

Employs 128-bit AES in CBC mode with HMAC SHA-256 integrity verification, ensuring archived contents cannot be decrypted or tampered with without the key.

Native & Responsive GUI

Built with Python Tkinter and themed ttk widgets — clean, lightweight, and fast on Windows, macOS, and Linux without external runtime bloat.

Technical Specifications

Component Specification
Cryptography Fernet (128-bit AES in CBC mode with PKCS7 padding + HMAC-SHA256)
Compression zlib Level 9 (Z_BEST_COMPRESSION)
Archive Format .7bl container format
GUI Architecture Python Tkinter & ttk Native Widgets
Supported OS Windows 10/11, macOS, Linux

Quick Start Guide

1. Clone the repository:

git clone https://github.com/sharankumar-r/Files-Compressor-Encryption.git
cd Files-Compressor-Encryption

2. Install dependencies:

pip install -r requirements.txt

3. Launch the application:

python Files_Compressor_Eng.py
